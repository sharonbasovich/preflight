# bob_sessions/

Exported IBM Bob task-session reports go here (Bob IDE chat → Views and More
Actions → History → open task → export). One file per task. Scrub credentials
before committing — the hackathon guide warns that detected IBM credentials in
the repo trigger account deactivation.

See `docs/BOB_ACCESS.md` for the access steps and suggested prompts, and
`docs/BOB_USAGE.md` for the Devin-vs-Bob work log.
